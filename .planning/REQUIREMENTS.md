# Requirements: new-house-management

**Defined:** 2026-09-19
**Core Value:** Make moving and home setup predictable and low-friction by centralizing inventory, budget, vendor tracking, and timeline management.

## v1 Requirements

### Inventory

- [ ] **INV-01**: Capture item with photo, name, approximate dimensions, and category
- [ ] **INV-02**: Tag items as "keep", "donate", "sell", or "discard"
- [ ] **INV-03**: Export inventory as CSV

### Budget

- [ ] **BUD-01**: Add cost items (renovation, furniture, mover) with estimated and actual fields
- [ ] **BUD-02**: Show budget summary by category and total
- [ ] **BUD-03**: Mark cost items as paid/unpaid

### Timeline

- [ ] **TIM-01**: Create move timeline with milestones and due dates
- [ ] **TIM-02**: Send reminders (local notifications or exported checklist)
- [ ] **TIM-03**: Mark milestones complete and record notes

### Vendors

- [ ] **VEND-01**: Add vendor contact, service type, notes, and appointment dates
- [ ] **VEND-02**: Link vendor interactions to inventory or budget items

## v2 Requirements

- **IMPORT-01**: Import inventory from photos using basic OCR/vision (deferred)
- **SYNC-01**: Sync across devices (deferred)

## Out of Scope

| Feature | Reason |
|--------|--------|
| Full payment processing | Not required for MVP; increases compliance scope |
| Real-time vendor chat | Not core to organizing tasks |
